# Sagor Sen — AI Automation Portfolio

A standalone dark/futuristic portfolio website built with plain HTML, CSS and JavaScript.

## Open locally
Double-click `index.html` or open it with Chrome.

## Files
- `index.html` — website structure/content
- `style.css` — complete visual design
- `script.js` — mobile menu + project detail modal
- `sagor-sen.png` — Sagor Sen's profile photo

## Customize
Edit the text in `index.html` for email, links, services and projects.

## Important
This version is frontend-only. A real admin project uploader, authentication, cloud image/video storage and database can be added later with Supabase or another backend.
